0. Assume .jar files are built under openems/build according to official doc

1. How to build docker file (about 15 minutes)
change Dockerfile accordingly, i.e. the last two lines

docker pull jdk-

docker build --no-cache -t openems-backend .
docker build --no-cache -t openems-edge .

2. How to run docker?
docker run -it -p 8080:8080 --name openems-backend openems-backend
docker run -it -p 8080:8080 --name openems-edge openems-edge
